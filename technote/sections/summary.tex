\paragraph{Reading this table honestly:} for \SrCdSb{}, the dark-photon
channel is the most defensible (its rate formula is exact given
$\varepsilon(\omega)$; only $\varepsilon(\omega)$ itself is
bracketed/modeled). The DM-electron channel is a genuine sensitivity trend,
not a quantitative prediction, because the crystal form factor's shape is
inherited from Si. The Migdal channel does not currently exist for this
material and would require new ELF input data, not a config change.
